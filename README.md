# XiaoZhi / Black Deck

An experimental embedded-AI hardware project by Dutch CyberWorks.

This repository will document the development of a portable device combining embedded AI, custom electronics, firmware configuration, and a 3D-printed enclosure.

## Project areas

- Device hardware and control layout
- XiaoZhi-compatible firmware research
- ESP32 and display integration
- Enclosure and lid design
- 3D-print preparation and fit testing
- Setup notes and field observations

## Status

Early development and documentation.

Hardware variants, display connections, firmware compatibility, and enclosure fit are being verified before final build instructions are published.

## Repository policy

This repository will contain original Dutch CyberWorks documentation and properly attributed references.

It will not contain:

- Passwords, API keys, or private credentials
- Unverified firmware binaries
- Third-party assets without confirmed redistribution rights
- Instructions intended for unauthorized access or abuse
